# dsh-turn-fold · 回合折叠

DeepSeek Harness Web 界面插件，参照 Codex 的折叠方式：每轮对话只保留一行「已完成，用时 …」，通过这一行把整轮的思考过程和回复分别收起或展开，不用再一条一条展开。

> 插件只改显示，不修改会话数据。卸载后界面恢复原样。

## 功能

- **标题行两个开关**：每轮「已完成，用时 X 分 X 秒」这一行的右侧多出「思考过程」和「回复」两个按钮。点标题文字本身也能切换思考过程。
- **思考过程放进滚动窗口**：展开后，整轮的思考、运行命令、工具调用都在一个限高窗口里滚动显示，不会把正文撑得很长。
- **窗口内一键展开或收起**：窗口里中间穿插的说明文字照常显示；两段文字之间的思考和工具调用合并成一行摘要，比如「思考 · 运行命令 5 · 工具调用 2」。窗口右上角的「展开全部 / 收起全部」一次展开或收起所有摘要，每行摘要也能单独点开。
- **查看工具详情**：窗口里点任意一条工具调用，会打开官方的调用详情。
- **回复折叠**：标题行的「回复」按钮，或回复下方操作栏里的折叠按钮，都能收起或展开这一轮的回复。
- **默认状态**：已完成的轮次默认收起思考过程、显示回复；正在运行的一轮保持官方的实时显示，跑完后自动折叠。

折叠状态只保存在当前页面的内存里，重启后恢复默认。

## 安装

在 DeepSeek Harness 侧栏 →「插件」→「添加插件」里填：

```
github:whoishuhu/dsh-turn-fold
```

也可以用命令行：

```bash
dsh plugin --profile <你的 profile> add github:whoishuhu/dsh-turn-fold
```

安装后重启 DeepSeek Harness，界面插件会在页面加载时注入。

## 兼容性

- 在 DSH `0.2.2-rc.1` 上开发和验证（见 `package.json` 的 `engines.dsh`）。
- 插件替换官方 Chat 的 `turn-process` 节点渲染器，并在 `conversation.chat.assistant-actions` 加一个按钮。官方 Chat 如果改了节点结构或行属性（`data-chat-node-key`、`data-chat-turn`），需要相应更新插件。
- 「工作步骤展示」选任何档位都能用，建议选「完全展开」或「详细」，避免和官方自带的折叠叠在一起。

## 卸载

在插件面板里移除，或：

```bash
dsh plugin --profile <你的 profile> remove dsh-turn-fold
```
